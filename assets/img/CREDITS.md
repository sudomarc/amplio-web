# Crédits images — placeholders

Toutes les images utilisées sur le site sont des **placeholders temporaires**
(licences Creative Commons, via l'API [Openverse](https://openverse.org)).
Elles n'illustrent aucune réalisation client réelle de Nova Agency.

Toutes les images sont chargées directement depuis leur CDN d'origine
(`live.staticflickr.com`) — aucun fichier binaire n'est stocké dans ce dépôt.
Elles sont servies en `loading="lazy"` hors ligne de flottaison et
dimensionnées via les attributs `width`/`height` pour éviter le layout shift.
